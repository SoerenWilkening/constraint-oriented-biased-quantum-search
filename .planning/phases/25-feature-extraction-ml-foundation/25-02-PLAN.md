<interfaces>
From Model.pyx (key attributes for feature extraction):
```python
# model.n — int, total variable count
# model.variables — dict {index: Variable}, each Variable has: index, name, lb, ub, vtype
# model.obj_expr — list of Expression objects (objective terms)
# model.con_expr — list of Expression objects (constraint terms)
# model.constraints_compiled — bool, True after close() called
# model.sense — MAXIMIZE or MINIMIZE
```

From Expression.pyx (iteration protocol):
```python
# Iterating an Expression yields term lists via c_liste():
# Each term is [coefficient, var_idx1, var_idx2, ...]
# For constraint expressions, last two elements are sense (int) and rhs (int) when sense != -2
# Filter: terms are lists, sense/rhs are ints
# Zero-length terms (len_literal[i] == 0) are already filtered by c_liste()
```

From Variable class:
```python
# Variable.index — int, variable index
# Variable.lb — int, lower bound
# Variable.ub — int, upper bound
# Variable.vtype — int, variable type constant (INTEGER from Constants)
```

Per-variable feature set (9 features, fixed order):
```python
VARIABLE_FEATURE_NAMES = [
    "degree",                    # Number of constraints this variable appears in
    "coeff_mean",               # Mean absolute coefficient across constraints
    "coeff_max",                # Max absolute coefficient
    "coeff_min",                # Min absolute coefficient (or 0 if not in any constraint)
    "objective_coefficient",     # Coefficient in objective function (0 if absent)
    "bounds_width",             # ub - lb (1 for binary)
    "is_integer",               # 1.0 if integer type, 0.0 otherwise
    "avg_neighbor_degree",      # Average degree of co-occurring variables
    "num_co_occurring_vars",    # Number of unique variables sharing a constraint
]
```

Instance-level feature set (11 features, fixed order):
```python
INSTANCE_FEATURE_NAMES = [
    "n_variables",              # Total number of variables
    "n_constraints",            # Total number of constraints
    "constraint_density",       # n_constraints / n_variables (0 if no variables)
    "constraint_variable_ratio",# Same as constraint_density
    "objective_density",        # Fraction of variables with nonzero objective coefficient
    "integer_variable_fraction",# Fraction of variables that are integer type
    "coeff_mean",              # Global mean of absolute constraint coefficients
    "coeff_std",               # Global std of absolute constraint coefficients
    "coeff_max",               # Global max absolute constraint coefficient
    "bounds_tightness_mean",   # Mean of (ub - lb) across all variables
    "bounds_tightness_std",    # Std of (ub - lb) across all variables
]
```

  <action>
Replace the stub FeatureExtractor in cbqs/ml/features.py with a full implementation. The file must contain:

1. **Imports:** `import numpy as np` and `from cbqs.Constants import INTEGER` (for variable type check).

2. **Module-level constants:**
   - `VARIABLE_FEATURE_NAMES` — list of 9 string names as defined in the interfaces section above.
   - `INSTANCE_FEATURE_NAMES` — list of 11 string names as defined in the interfaces section above.

3. **Helper function `_parse_expression_terms(expr)`:**
   - Takes an Expression object, calls `list(expr)` to get all elements.
   - Filters elements: keep only items that are `list` instances with `len >= 2` (these are terms). Discard int elements (sense/rhs values appended by constraint expressions).
   - For each valid term: `coeff = term[0]`, `var_indices = tuple(term[1:])`.
   - Returns a list of `(coefficient, var_indices_tuple)` pairs.

4. **FeatureExtractor class** with:
   - **Class docstring** explaining it extracts structural features from CBQS Model objects for ML-based branching weight prediction.
   - **`feature_names` property** returning `VARIABLE_FEATURE_NAMES`.
   - **`instance_feature_names` property** returning `INSTANCE_FEATURE_NAMES`.

   - **`extract_variable_features(self, model)` method:**
     - Validate: if `not model.constraints_compiled`, raise `ValueError('Model must be closed before feature extraction')`.
     - Get sorted variable indices: `var_indices = sorted(model.variables.keys())`.
     - Create `n = len(var_indices)` and mapping `idx_to_row = {idx: row for row, idx in enumerate(var_indices)}`.
     - Initialize feature matrix: `features = np.zeros((n, 9), dtype=np.float64)`.
     - **Objective coefficients:** For each expression in `model.obj_expr`, parse terms with `_parse_expression_terms`. For each term with exactly one variable index (`len(var_indices_tuple) == 1`), accumulate `abs(coeff)` to the corresponding variable's "objective_coefficient" feature (column 4). For multi-variable terms (products), add the `abs(coeff)` to each participating variable.
     - **Constraint participation:** For each expression in `model.con_expr`:
       - Parse terms with `_parse_expression_terms`.
       - Collect all variable indices appearing in this constraint into a set `vars_in_constraint`.
       - For each term, for each var_idx in the term's variable indices:
         - Increment `degree` (column 0).
         - Append `abs(coeff)` to a per-variable coefficient list (use a temporary dict).
       - After processing all terms in this constraint, for each variable in `vars_in_constraint`:
         - Add all OTHER variables in `vars_in_constraint` to that variable's co-occurring set (use a temporary dict).
     - **Coefficient statistics:** For each variable with coefficient data:
       - Column 1 (coeff_mean): `np.mean(coefficients)`.
       - Column 2 (coeff_max): `np.max(coefficients)`.
       - Column 3 (coeff_min): `np.min(coefficients)`.
       - If no coefficients (degree == 0), leave as 0.
     - **Variable properties:** For each variable (via `model.variables[idx]`):
       - Column 5 (bounds_width): `var.ub - var.lb`.
       - Column 6 (is_integer): `1.0` if `var.vtype == INTEGER` else `0.0`.
     - **Neighbor features:** For each variable:
       - Column 7 (avg_neighbor_degree): mean of degree values of all co-occurring variables. If no co-occurring variables, leave as 0.
       - Column 8 (num_co_occurring_vars): count of unique co-occurring variables.
     - **Normalization:** Apply per-column z-score normalization. For each column: compute mean and std. If std > 0, replace `column = (column - mean) / std`. If std == 0, set column to zeros (avoid NaN).
     - Return the numpy array of shape `(n, 9)`.

   - **`extract_instance_features(self, model)` method:**
     - Validate: if `not model.constraints_compiled`, raise `ValueError('Model must be closed before feature extraction')`.
     - Initialize `features = np.zeros(11, dtype=np.float64)`.
     - `n_vars = model.n` (or `len(model.variables)`).
     - `n_cons = len(model.con_expr)`.
     - Column 0: `n_variables = n_vars`.
     - Column 1: `n_constraints = n_cons`.
     - Column 2: `constraint_density = n_cons / n_vars if n_vars > 0 else 0`.
     - Column 3: `constraint_variable_ratio = n_cons / n_vars if n_vars > 0 else 0`.
     - **Objective density:** Parse all `model.obj_expr` terms. Count unique variable indices with nonzero coefficients. Column 4: `count / n_vars if n_vars > 0 else 0`.
     - **Integer fraction:** Count variables with `vtype == INTEGER`. Column 5: `count / n_vars if n_vars > 0 else 0`.
     - **Global coefficient stats:** Collect all `abs(coeff)` from all constraint expression terms. Column 6: mean (0 if empty). Column 7: std (0 if empty). Column 8: max (0 if empty).
     - **Bounds tightness:** Collect `var.ub - var.lb` for all variables. Column 9: mean (0 if empty). Column 10: std (0 if empty).
     - Return the numpy array of shape `(11,)`.

CRITICAL implementation notes:
- Use `_parse_expression_terms` consistently for ALL expression parsing — never access Expression internals directly.
- Handle the edge case where `model.con_expr` is empty: all constraint-related features should be 0.
- Handle the edge case where `model.obj_expr` is empty: objective coefficients should be 0.
- Variable indices in expressions may not all be in `model.variables` (defensive: skip any var_idx not in `idx_to_row`).
- Import INTEGER from cbqs.Constants for the vtype check.
