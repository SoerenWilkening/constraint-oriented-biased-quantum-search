  <files>cbqs/src/Expression.h, cbqs/src/constraint.h</files>

**Expression.h changes:**

1. Add `#include "dyn_expr.h"` after existing includes

2. **Remove MAXCLAUSESIZE entirely** (per CONTEXT.md decision: "MAXCLAUSESIZE: Remove entirely — no artificial limits, dynamic allocation handles any size")

3. Replace the expression_t struct with a simple typedef:
   ```c
   typedef dyn_expression_t expression_t;
   ```

   This is the simplest approach:
   - No wrapper struct, no dual-storage confusion
   - expression_t IS dyn_expression_t
   - All fields (literals, len_literal, expr_size, sense, rhs) are already in dyn_expression_t
   - Consumer code accessing expr->literals still works (dyn_expression_t has this field)

```c
// Used for indexing into constraint variable arrays
if (cls == 0) return clause_offset * (MAXCLAUSESIZE - 1);
```

This is constraint-specific storage, not Expression storage. To avoid confusion and honor the "remove MAXCLAUSESIZE" decision:

1. Add a new constant at the top of constraint.h:
   ```c
   #define CONSTRAINT_VARS_PER_CLAUSE 4  // Max variables per clause in constraint storage
   ```

2. Replace MAXCLAUSESIZE with CONSTRAINT_VARS_PER_CLAUSE in:
   - `first_variable_index()` function (lines 85-86)
   - `variable_index()` function (line 90)

This removes the MAXCLAUSESIZE name entirely while keeping constraint indexing working.

<task type="auto">
  <name>Task 2b: Migrate Expression.c add/sub operations</name>
  <files>cbqs/src/Expression.c</files>
  <action>
Migrate compound add/sub operations:

1. **add_constant()**:
   ```c
   void add_constant(expression_t *expr, int64_t constant) {
       dyn_expr_add_constant(expr, constant);
   }
   ```

2. **add_variable()**:
   ```c
   void add_variable(expression_t *expr, int64_t index) {
       dyn_expr_add_variable(expr, index);
   }
   ```

3. **add_expression()**:
   Loop through expr2's terms and add each to expr1:
   ```c
   void add_expression(expression_t *expr1, expression_t *expr2) {
       int64_t *lits = dyn_expr_literals(expr2);
       int *lens = dyn_expr_len_literal(expr2);
       for (size_t i = 0; i < expr2->expr_size; i++) {
           int64_t coeff = lits[i * MAX_VARS_PER_TERM];
           int num_vars = lens[i] - 1;
           if (num_vars > 0) {
               dyn_expr_add_term(expr1, coeff, &lits[i * MAX_VARS_PER_TERM + 1], num_vars);
           } else {
               dyn_expr_add_constant(expr1, coeff);
           }
       }
   }
   ```

4. **sub_constant()**:
   ```c
   void sub_constant(expression_t *expr, int64_t constant) {
       dyn_expr_add_constant(expr, -constant);
   }
   ```

5. **sub_variable()**:
   Add term with coefficient -1:
   ```c
   void sub_variable(expression_t *expr, int64_t index) {
       dyn_expr_add_term(expr, -1, &index, 1);
   }
   ```

6. **sub_expression()**:
   Same as add_expression but negate coefficients:
   ```c
   void sub_expression(expression_t *expr1, expression_t *expr2) {
       int64_t *lits = dyn_expr_literals(expr2);
       int *lens = dyn_expr_len_literal(expr2);
       for (size_t i = 0; i < expr2->expr_size; i++) {
           int64_t coeff = -lits[i * MAX_VARS_PER_TERM];
           int num_vars = lens[i] - 1;
           if (num_vars > 0) {
               dyn_expr_add_term(expr1, coeff, &lits[i * MAX_VARS_PER_TERM + 1], num_vars);
           } else {
               dyn_expr_add_constant(expr1, coeff);
           }
       }
   }
   ```

  <action>
Migrate multiply and helper functions:

1. **multiply_constant()**:
   Modify coefficients in place (no growth, safe to access directly):
   ```c
   void multiply_constant(expression_t *expr, int64_t constant) {
       int64_t *lits = dyn_expr_literals(expr);
       for (size_t i = 0; i < expr->expr_size; i++) {
           lits[i * MAX_VARS_PER_TERM] *= constant;
       }
   }
   ```

2. **multiply_variable()**:
   Append variable index to each term (modifies len_literal too):
   ```c
   void multiply_variable(expression_t *expr, int64_t index) {
       int64_t *lits = dyn_expr_literals(expr);
       int *lens = dyn_expr_len_literal(expr);
       for (size_t i = 0; i < expr->expr_size; i++) {
           int current_len = lens[i];
           if (current_len < MAX_VARS_PER_TERM) {
               lits[i * MAX_VARS_PER_TERM + current_len] = index;
               lens[i]++;
           }
           // If already at max variables, silently ignore (existing behavior)
       }
   }
   ```

3. **multiply_expressions()**:
   Uses init_expression and add_expression internally — already migrated. Keep existing logic.

4. **Helper functions** (len_literal, expr_index, compare_tuples, sort_expression, merge_expression, print_expression):

       return MAX_VARS_PER_TERM * lit + ind;  // Replace MAXCLAUSESIZE
