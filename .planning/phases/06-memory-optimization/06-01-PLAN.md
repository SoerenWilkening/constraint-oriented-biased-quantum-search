Create arena allocator with the following design:

**arena.h:**
```c
#ifndef ARENA_H
#define ARENA_H

#include <stddef.h>

#define ARENA_DEFAULT_SIZE (1024 * 1024)   // 1MB initial chunk
#define ARENA_CHUNK_SIZE   (256 * 1024)    // 256KB overflow chunks

typedef struct arena_chunk {
    struct arena_chunk *next;  // Linked list of chunks
    size_t size;               // Chunk size (bytes available in data[])
    size_t used;               // Current offset in data[]
    char data[];               // Flexible array member
} arena_chunk_t;

typedef struct {
    arena_chunk_t *head;       // First chunk (initial allocation)
    arena_chunk_t *current;    // Current allocation chunk
} arena_t;

// Create arena with initial_size bytes (use ARENA_DEFAULT_SIZE for default)
arena_t *arena_create(size_t initial_size);

// Allocate size bytes with given alignment (must be power of 2, typically 8)
void *arena_alloc(arena_t *arena, size_t size, size_t align);

// Reset all chunks to start (keeps memory allocated for reuse)
void arena_reset(arena_t *arena);

// Free arena and all chunks
void arena_free(arena_t *arena);

// Debug: get total allocated bytes across all chunks
size_t arena_allocated(arena_t *arena);

// Debug: get currently used bytes
size_t arena_used(arena_t *arena);

#endif // ARENA_H
```

**arena.c implementation requirements:**
- arena_create: malloc arena_t + initial chunk using flexible array member
- arena_alloc: calculate alignment padding, check if fits, chain new chunk on overflow
- arena_reset: iterate all chunks, set used=0, reset current to head
- arena_free: iterate all chunks, free each, free arena_t
- Handle NULL arena gracefully (no-op or return 0/NULL)

Key implementation for arena_alloc (from research):
```c
uintptr_t ptr = (uintptr_t)(chunk->data + chunk->used);
size_t padding = (-(ptrdiff_t)ptr) & (align - 1);
if (chunk->used + padding + size > chunk->size) {
    // allocate new chunk...
}
void *result = chunk->data + chunk->used + padding;
chunk->used += padding + size;
```
