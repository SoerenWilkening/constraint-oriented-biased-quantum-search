**Implementation in adaptation.py:**

```python
"""Online adaptive solve with EMA weight updates."""
from dataclasses import dataclass
from typing import List, Dict, Optional, Union

import numpy as np

from cbqs.ml.training import WeightPredictor, _rank_result


@dataclass
class AdaptiveResult:
    """Result of an adaptive multi-round solve.

    Attributes
    ----------
    best_result : OptimizeResult
        The OptimizeResult from the best-performing round.
    best_weights : numpy.ndarray
        The branching weights that produced best_result.
    history : list of dict
        Per-round metrics: {round, objective, feasible, reward, weights}.
    n_rounds_completed : int
        Total number of rounds executed.
    """
    best_result: object
    best_weights: np.ndarray
    history: List[Dict]
    n_rounds_completed: int
```

**Helper: _resolve_initial_weights(initial_weights, model, n_vars)**
- If `initial_weights is None`: return `np.ones(n_vars)`
- If `isinstance(initial_weights, WeightPredictor)`: return `initial_weights.predict(model).copy()`
- Otherwise: `weights = np.array(initial_weights, dtype=np.float64).copy()`. Validate `len(weights) == n_vars`, raise ValueError on mismatch. Return weights.

**Helper: _compute_reward(current_result, prev_result, current_weights)**
Compute combined reward signal:
- Feasibility component: `1.0` if `current_result.feasible` else `0.0`
- Objective improvement: if prev_result exists and prev_result.objective != 0, compute `(current - prev) / abs(prev)`, clamp to [0, 1]. If first round or prev objective is 0, use 0.5 (neutral).
- Combined reward: `0.5 * feasibility + 0.5 * obj_improvement`
- `reward_adjusted = reward * current_weights` (scale current weights by reward)
- Return `(reward, reward_adjusted)`

**Main function: adaptive_solve(model, n_rounds=5, stopping_time=5, num_workers=2, ema_alpha=0.3, seed=None, initial_weights=None, verbose=True)**

Implementation flow:
1. `n_vars = len(model.variables)`
2. Resolve initial weights via `_resolve_initial_weights`
3. Save original: `original_weights = model.get_param('branching_weights')`
4. Create RNG: `rng = np.random.RandomState(seed)`
5. Initialize: `history = []`, `best_result = None`, `best_weights = None`, `prev_result = None`, `current_weights = initial_weights_resolved`
6. try/finally block — finally restores: `model.set_param('branching_weights', original_weights)`
7. Loop for `n_rounds`:
   a. Derive per-round seed: `round_seed = int(rng.randint(0, 2**31))`
   b. Set model params: `model.seed = round_seed` (property, NOT set_param), `model.set_param('branching_weights', current_weights.copy())`, `model.set_param('stopping_time', stopping_time)`, `model.set_param('num_workers', num_workers)`
   c. `result = model.solve()`
   d. Compute reward: `reward, reward_adjusted = _compute_reward(result, prev_result, current_weights)`
   e. Track best: if `best_result is None or _rank_result(result) > _rank_result(best_result)`: update `best_result = result`, `best_weights = current_weights.copy()`
   f. Record history entry: `{'round': round_idx + 1, 'objective': result.objective, 'feasible': result.feasible, 'reward': reward, 'weights': current_weights.copy()}`
   g. Verbose print: `f"Round {round_idx+1}/{n_rounds}: obj={result.objective}, feasible={result.feasible}, reward={reward:.4f}"`
   h. EMA update (skip after last round): `new_weights = ema_alpha * reward_adjusted + (1 - ema_alpha) * current_weights`, `current_weights = np.clip(new_weights, 0, None)`
   i. `prev_result = result`
8. Return `AdaptiveResult(best_result=best_result, best_weights=best_weights, history=history, n_rounds_completed=n_rounds)`
