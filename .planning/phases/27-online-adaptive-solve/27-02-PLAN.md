Add determinism and thread safety tests to the existing `tests/test_ml_adaptation.py`. Reuse the `_make_test_model(n_vars)` helper from Task 1 of Plan 01.

**Determinism tests (ADAPT-03):**

1. **test_determinism_same_seed_same_weights** — Call `adaptive_solve(model, n_rounds=3, stopping_time=2, num_workers=1, seed=42, verbose=False)` twice on the same model. For each pair of history entries, assert `np.array_equal(h1['weights'], h2['weights'])`. All per-round weights must be identical.

2. **test_determinism_same_seed_same_objectives** — Same two calls as above. Assert `h1['objective'] == h2['objective']` and `h1['feasible'] == h2['feasible']` for every round pair.

3. **test_determinism_same_seed_same_best_result** — Same two calls. Assert `r1.best_result.objective == r2.best_result.objective` and `r1.best_result.feasible == r2.best_result.feasible`. Also `np.array_equal(r1.best_weights, r2.best_weights)`.

4. **test_determinism_different_seeds_differ** — Call with seed=42 and seed=99 on the same model. At least one round's weights should differ between the two runs (test that determinism is NOT trivial — seeds matter).

**Thread safety tests (ADAPT-04):**

5. **test_concurrent_different_models_no_error** — Create two different models (different sizes, e.g., 5 vars and 8 vars). Run adaptive_solve concurrently using `threading.Thread`. Both threads must complete without errors. Use a results list and an errors list to capture thread outcomes.

6. **test_concurrent_correct_shapes** — After concurrent runs from test 5, verify `results[0].best_weights.shape == (5,)` and `results[1].best_weights.shape == (8,)`. Each result's weights must match its model's variable count.

7. **test_concurrent_independent_histories** — Each concurrent result's history length equals n_rounds. Weights in each history entry have the correct size for their respective model (5 or 8).

Note: Use `num_workers=1` in determinism tests to eliminate solver-internal thread nondeterminism. Use short `stopping_time=2` and small models to keep tests fast. For concurrent tests, use `n_rounds=3, stopping_time=2, num_workers=1, seed=42, verbose=False`.

These tests should PASS immediately against the Plan 01 implementation (the implementation already handles determinism via seed propagation and thread safety via function-local state). If any test fails, debug the implementation to understand why and fix the test expectations or the implementation as needed.

Run all adaptation tests to confirm everything passes.
