**Branching.h -- Replace BranchingStats_t struct:**

Delete the old struct fields (objective_factor, obj_dependent, constraint_factor, constraint_dependent) and replace with the new unified design:

```c
typedef struct {
    double *branching_weights;  /* Per-variable weights (NULL = no weights) */
    int num_weights;            /* Length of branching_weights (0 when NULL) */

    double branching_factor;    /* Factor for branching_weights term (default 1.0) */
    double bias_factor;         /* Factor for assignment_bias term (default 1.0) */
    double bias;                /* Assignment bias value (default 5.0) */
    double look_factor;         /* Factor for look-ahead term (default 0.0) */
} BranchingStats_t;
```

**Branching.h -- Rewrite BranchingFunction inline:**

Replace the old 4-term formula with the 3-term formula (or 2-term when branching_weights is NULL):

1. Read branching_factor, bias_factor, look_factor from stats.
2. If diffcount == 0, force look_factor = 0 (matches current behavior).
3. Compute lookahead_0_probability: 0 if diffcount < 0, else 1.0.
4. Compute assignment_bias = (stats->bias + 1.0) / (stats->bias + 2.0).
5. Compute factor_sum: start with bias_factor + look_factor. If branching_weights is not NULL and index < num_weights, add branching_factor and read w = branching_weights[index].
6. Guard: if factor_sum <= 0.0, return 0.5 (uniform random -- division by zero protection).
7. normalizer = 1.0 / factor_sum.
8. Compute value: sum of up to 3 terms (branching_weights term only if array is non-NULL and index < num_weights).
9. Apply bit_S / bit_T logic identical to current code:
   - bit_T==0 && bit_S==0: total_bias = value
   - bit_T==0 && bit_S==1: total_bias = 1 - value
   - bit_T==1 && bit_S==0: total_bias = 1 - value
   - bit_T==1 && bit_S==1: total_bias = value

**Branching.h -- Remove old deprecated function declarations:**

Delete declarations for set_factors(), set_bias(), set_obj_dependence(), set_constraint_dependence(). Keep the extern BranchingStats global declaration (Phase 16 removes it).

**Branching.c -- Update global BranchingStats defaults:**

Change the global initializer to use new field names:
```c

    .branching_weights = NULL,
    .num_weights = 0,
    .branching_factor = 1.0,
    .bias_factor = 1,
    .bias = 5,
    .look_factor = 0.0
};
```

**Branching.c -- Remove old global setter functions:**

Delete the function bodies for set_factors(), set_bias(), set_obj_dependence(), set_constraint_dependence(). These are removed immediately per user decision (no deprecation period in v2.0).

**Branching.c -- Update StateProbability:**
