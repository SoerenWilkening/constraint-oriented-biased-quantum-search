**In `run_sampling()`:**

1. Add `import time as time_mod` at the top of the file (or use the existing `time` import -- check what's available; currently uses `time.time()`). Use `time_mod.monotonic()` for timing.

2. Record preprocessing start time before any setup work:
   ```python
   preprocess_start = time_mod.monotonic()
   ```

3. Record preprocessing end / solve start time just before the `with nogil:` block that calls `ctg()`:
   ```python
   preprocess_end = time_mod.monotonic()
   preprocessing_time_ms = (preprocess_end - preprocess_start) * 1000.0
   ```

4. Create a history callback wrapper closure BEFORE setting `python_callback`. The wrapper:
   - Maintains a local `history` list and `_prev_best` list (mutable closure variable)
   - On each call: reads `mod.mod[0].global_opt[0].tot_profit * mod.sense` for objective, `mod.mod[0].runtime * 1000.0` for elapsed_ms, `mod.mod[0].global_opt[0].feasible` for is_feasible, `mod.mod[0].qtg_applications` for iteration
   - Only appends to history if objective differs from `_prev_best[0]`
   - After recording, calls the original user callback if not None
   - Set `python_callback = _history_callback` (the wrapper) instead of the raw user callback

   Note: `mod.sense` is an attribute on the Model object passed to run_sampling. Access it as `mod.sense`.

5. Expand the return tuple to include `history` and `preprocessing_time_ms`:
   ```python
   return cur_sol, mod.mod[0].qtg_applications, feasible, arr, t_total, incumb, history, preprocessing_time_ms
   ```
   (Was 6-tuple, now 8-tuple)

**In `run_local_search()`:**

1. Record preprocessing time similarly (before/after setup, before `with nogil` local_search call).

2. Create history callback wrapper with same pattern as run_sampling. For local_search, the callback fires every iteration (not just on improvement), so the `_prev_best` check is essential.

3. Read objective as `mod.mod[0].global_opt[0].tot_profit * mod.sense` for local_search too. Use `mod.mod[0].runtime * 1000.0` for elapsed_ms.

4. Expand return to include history, preprocessing_time_ms, and solve_time_ms:
   ```python
   solve_time_ms = mod.mod[0].runtime * 1000.0
   return cur_sol, history, preprocessing_time_ms, solve_time_ms
   ```
   (Was just `cur_sol`, now 4-tuple)

**Important Cython considerations:**
- The `python_callback` is a module-level `cdef object`. It's set before `with nogil` blocks. The closure captures the Model object which has GIL-requiring access -- this is fine because `my_callback_c()` acquires the GIL.
- Do NOT modify the C callback signature or `my_callback_c()`.
- Access `mod.sense` (Python attribute on Model class) not `mod.mod[0].sense` (might not exist in C struct).
