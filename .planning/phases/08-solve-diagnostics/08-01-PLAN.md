  <name>Task 1: Create OptimizeResult class</name>
  <files>cbqs/result.py</files>
  <action>
Create `cbqs/result.py` with a pure Python `OptimizeResult` class. This is a regular class (not dataclass, not Cython cdef class).

**Constructor** takes keyword-only arguments:
- `solution` (numpy array or list) -- the solution vector
- `objective` (float) -- objective value (sign-corrected for user-facing)
- `feasible` (bool) -- whether solution satisfies all constraints
- `solve_time` (float) -- solve time in milliseconds
- `preprocessing_time` (float) -- preprocessing time in milliseconds
- `iterations` (int) -- iteration count
- `oracle_calls` (int) -- number of oracle (QTG) calls
- `history` (list of tuples) -- improvement history, each entry is (iteration, objective_value, elapsed_ms, is_feasible)
- `verified` (bool or None) -- post-solve verification result (None if not run)
- `violations` (list of str or None) -- violation descriptions from verification
- `num_threads` (int) -- number of threads used
- `seed` (int) -- random seed used

All arguments stored as instance attributes.

**Properties:**
- `time` -- returns `self.preprocessing_time + self.solve_time` (total time in ms)

**Methods:**
- `__repr__()` -- returns `OptimizeResult(obj=42.0, feasible=True, time=1.23ms, iterations=5000)` format. Use `:.2f` for time. Show objective as-is (no special formatting for int vs float).
- `summary()` -- returns a multi-line string formatted report containing all fields, grouped logically:
  - Solution section: solution array (truncated if >20 elements), objective, feasible
  - Timing section: preprocessing_time, solve_time, total time
  - Search section: iterations, oracle_calls
  - History section: number of improvement entries, first and last entry if any
  - Verification section: verified status, violations if any
  - Reproducibility section: num_threads, seed
- `to_dict()` -- returns a JSON-serializable dictionary with all fields. Convert numpy arrays to lists. Convert tuples in history to lists for JSON compatibility.

Do NOT import numpy at module level. Use a try/except or check at runtime for numpy array conversion in to_dict(). This keeps the module importable without numpy for basic testing.
  </action>

  </verify>
