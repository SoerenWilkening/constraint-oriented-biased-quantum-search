  <name>Task 1: Implement evaluate_weights with convergence speed metrics</name>
  <files>cbqs/ml/training.py, tests/test_ml_training.py</files>
  <behavior>
    - evaluate_weights(test_models, strategies, stopping_time=5, num_workers=2) returns dict with per-strategy metrics
    - Each strategy entry has keys: mean_objective, feasibility_rate, mean_time_to_best, speedup_vs_uniform
    - 'uniform' baseline is auto-added when not in strategies dict (uniform weights = np.ones(n_vars))
    - User-provided 'uniform' key overrides the auto-added one (dict update order: uniform first, then user strategies)
    - _compute_time_to_best(history, stopping_time) returns elapsed_seconds of first occurrence of max value in history
    - _compute_time_to_best([], stopping_time) returns stopping_time (ceiling penalty for empty history)
    - speedup_vs_uniform = uniform_ttb / strategy_ttb; if uniform_ttb == 0 then speedup = 1.0; if strategy_ttb == 0 and uniform_ttb > 0 then speedup = float('inf')
    - Printed table has columns: Strategy | Mean Objective | Feasibility Rate | Time-to-Best | Speedup vs Uniform
    - branching_weights are reset to None after each solve (state cleanup)
  </behavior>
  <action>
Add three new functions to `cbqs/ml/training.py` AFTER the existing `evaluate()` function:

1. **`_compute_time_to_best(history, stopping_time)`** — private helper.
   - If `history` is empty, return `stopping_time` (ceiling penalty).
   - Find the maximum value across all `(value, elapsed_seconds)` tuples in history.
   - Return the `elapsed_seconds` of the FIRST entry whose value equals the max.
   - Fallback: return `stopping_time` (should not be reached).

2. **`_print_evaluation_table(results)`** — private printer.
   - Extends the existing `_print_comparison_table` pattern with two additional columns: Time-to-Best and Speedup vs Uniform.
   - Header: `Strategy | Mean Objective | Feasibility Rate | Time-to-Best | Speedup vs Uniform`
   - Speedup column formatted with 2 decimal places and an 'x' suffix (e.g., "2.30x").
   - Uses `-` separators matching header width.

3. **`evaluate_weights(test_models, strategies, stopping_time=5, num_workers=2)`** — public function.
   - `strategies` is a dict of `{name: callable(model) -> weights_array}`.
   - Build `all_strategies` by starting with `{'uniform': lambda m: np.ones(len(m.variables))}`, then calling `all_strategies.update(strategies)` (so user 'uniform' overrides).
   - For each strategy, for each model: set branching_weights, stopping_time, num_workers via set_param; solve; collect result.objective, result.feasible, and compute time-to-best from result.history; reset branching_weights to None.
   - Aggregate: mean_objective = np.mean(objectives), feasibility_rate = feasible_count / n_models, mean_time_to_best = np.mean(times_to_best).
   - Compute speedup_vs_uniform for each strategy: if uniform mean_time_to_best > 0, speedup = uniform_ttb / strategy_ttb (use float('inf') if strategy_ttb == 0); if uniform_ttb == 0, speedup = 1.0.
   - Call `_print_evaluation_table(results)`.
   - Return the results dict.

Then add a **`TestEvaluateWeights`** test class to `tests/test_ml_training.py` with these tests:

- `test_evaluate_weights_returns_dict_with_metrics` — Call with a simple constant-weight strategy, verify result dict has 'uniform' key and strategy key, each with all four metric keys.
- `test_evaluate_weights_auto_adds_uniform` — Pass strategies without 'uniform', verify 'uniform' appears in result.
- `test_evaluate_weights_prints_table` — Use capsys, verify printed output contains strategy names and column headers.
- `test_evaluate_weights_speedup_vs_uniform` — Verify speedup_vs_uniform is a float >= 0 for each strategy.
- `test_evaluate_weights_time_to_best_range` — Verify mean_time_to_best is between 0 and stopping_time for each strategy.
- `test_compute_time_to_best_empty_history` — Test _compute_time_to_best with empty list returns stopping_time.
- `test_compute_time_to_best_finds_first_max` — Test with a known history list, verify it returns the elapsed time of the first occurrence of the best value.

Use the existing `_make_test_model(n_vars)` helper. Use `stopping_time=1, num_workers=1` in tests for fast execution.
