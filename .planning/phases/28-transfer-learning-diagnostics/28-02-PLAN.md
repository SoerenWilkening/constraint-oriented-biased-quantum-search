  <action>
Add `validate_transfer()` to `cbqs/ml/training.py` AFTER the `evaluate_weights()` function:

```python
def validate_transfer(train_models, test_models, n_strategies=10,
                      stopping_time=5, num_workers=2, random_state=None):
```

**Parameters:**
- `train_models`: list of Model — small instances for training data collection
- `test_models`: list of Model — larger instances for evaluation
- `n_strategies`: int — number of random strategies per model for data collection (passed to collect_training_data)
- `stopping_time`: float — solve time budget in seconds (passed to both collect_training_data and evaluate_weights)
- `num_workers`: int — solver threads (passed to both)
- `random_state`: int or None — random seed (passed to collect_training_data and WeightPredictor)

**Implementation (3 steps):**

1. **Collect training data:** Call `collect_training_data(train_models, n_strategies=n_strategies, stopping_time=stopping_time, num_workers=num_workers, random_state=random_state)`.

2. **Train predictor:** Create `WeightPredictor(random_state=random_state)`, call `predictor.fit(training_pairs)`.

3. **Evaluate on test models:** Build strategies dict `{'learned': lambda m: predictor.predict(m)}`, call `evaluate_weights(test_models, strategies, stopping_time=stopping_time, num_workers=num_workers)`.

4. **Return:** `(results, predictor)` tuple.

**Docstring:** Follow the existing module docstring style. Document all parameters, return type (tuple of dict and WeightPredictor), and include a brief example.

Then add a **`TestValidateTransfer`** test class to `tests/test_ml_training.py`:

- `test_validate_transfer_returns_tuple` — Call with small train models (n_vars=3) and test models (n_vars=5), verify return is a 2-tuple of (dict, WeightPredictor).
- `test_validate_transfer_results_format` — Verify the results dict has 'learned' and 'uniform' keys, each with all four metric keys (mean_objective, feasibility_rate, mean_time_to_best, speedup_vs_uniform).
- `test_validate_transfer_predictor_reusable` — Verify the returned predictor can call predict() on a new model and return a valid weights array.
- `test_validate_transfer_different_sizes` — Train on n_vars=3 models, evaluate on n_vars=8 models. Verify it completes without error and the returned predictor can predict on an n_vars=8 model.

Use `n_strategies=2, stopping_time=1, num_workers=1` in all tests for fast execution. Use `random_state=42` for reproducibility.
