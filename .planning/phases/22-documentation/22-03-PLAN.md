<!-- Key algorithms requiring documentation -->

1. Branching formula (Branching.h):
   - BranchingFunction(): inline function computing per-variable branching probability
   - 3-term formula: branching_weights + assignment_bias + look_ahead
   - Normalized by factor_sum, with bit_S/bit_T logic for direction
   - StateProbability(): multiplies per-bit branching probabilities

2. Preprocessing (constraint.c):
   - preprocessing(): dense constraint preprocessing — builds index structures
   - preprocessing_sparse(): sparse constraint preprocessing — uses CSR-like format
   - Both build lookup structures used by the solver for efficient evaluation

3. Look-ahead logic (solver.c):
   - look_ahead_correct(): recursive function checking feasibility of partial assignments
   - Used in sampling to prune infeasible branches early
   - Called from the main sampling loop with configurable depth

4. Local search (local_search.c):
   - explore_neighbourhood(): evaluates all k-flip neighbors
   - accept_best_routine(): selects best improving move
   - Overall loop: iterative improvement with tabu list and restart logic
   - Incremental evaluation via adjusted_constraint_violation()

5. Approximate state sampler (approximate_state_sampler.c):
   - Uses same look-ahead logic but in the context of approximate simulation
</interfaces>
