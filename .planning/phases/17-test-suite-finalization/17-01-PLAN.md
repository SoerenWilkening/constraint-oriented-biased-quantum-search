**Python tests — append to tests/test_branching_propagation.py:**

Add a new test class `TestBranchingWeightsCoverage` with these tests:

1. `test_different_weights_different_behavior`: Same seed (42), same problem (n=20 knapsack), but DIFFERENT branching_weights — one uniform [1.0]*n, one extremely skewed [float(10*i+1) for i in range(n)]. Use num_workers=1, stopping_time=5. Assert both produce valid OptimizeResult. Note: we cannot guarantee different objectives (solver may converge to same optimum), but this exercises the full propagation path with varied inputs.

2. `test_all_zero_weights`: Set branching_weights=[0.0]*n (n=20). This should trigger the division-by-zero guard in BranchingFunction. Verify the solver completes without crashing and returns a valid OptimizeResult with non-negative objective.

3. `test_branching_weights_large_n`: Create a knapsack with n=100 variables. Set branching_weights=[float(i+1) for i in range(100)]. Use stopping_time=3, num_workers=1. Verify solve completes and returns valid OptimizeResult. This tests scalability of weights propagation.

4. `test_branching_weights_with_all_factors`: Set branching_weights + branching_factor=0.5 + bias_factor=1.5 + look_ahead_factor=0.3 + branching_bias=10.0 all together. Use num_workers=1, stopping_time=2. Verify solve completes and returns valid OptimizeResult. This exercises the full 3-term formula from Python.

Use the existing `_make_knapsack_model(n)` helper for all tests. Follow existing test patterns exactly (importorskip, OptimizeResult assertion, etc.).

**C tests — append to tests/test_branching.c:**

Add these new test functions (before the `main()` function) and register them in the `tests[]` array:

1. `test_branching_function_all_factors_zero`: Set branching_factor=0, bias_factor=0, look_factor=0. Call BranchingFunction. Assert result == 0.5 (division-by-zero guard). This verifies the guard works with all factors zero (currently only tested with non-zero bias_factor).

2. `test_branching_weights_realloc_different_sizes`: Set weights of size 2, then overwrite with size 5, then clear with NULL. Verify num_weights and stored values after each operation. Verify L1 normalization after realloc (first weight of [1,2,3,4,5] should be 1/15). This tests memory reallocation with different sizes (existing overwrite test uses same size).

3. `test_branching_weights_single_element`: Set weights=[1.0] (single element). Verify num_weights=1, stored value=1.0 (L1 norm of [1.0]=1.0). Call BranchingFunction with branching_factor=1.0, bias_factor=0, look_factor=0, index=0. Assert result = 1/(1) * 1.0 * 1.0 = 1.0 (or 0.0 if bits differ). This tests the edge case of a single-variable problem.
