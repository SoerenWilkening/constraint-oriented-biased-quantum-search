2. Sets `CMAKE_C_STANDARD 11`.
3. Uses `FetchContent_Declare` to fetch CMocka 1.1.7 from https://git.cryptomilk.org/projects/cmocka.git (tag `cmocka-1.1.7`). Set `WITH_STATIC_LIB ON`, `WITH_EXAMPLES OFF` as cache variables before `FetchContent_MakeAvailable(cmocka)`.
4. Defines a helper function `add_cmocka_test(NAME sources...)` that:
   - Creates an executable with the given sources PLUS all C source files from `${CMAKE_CURRENT_SOURCE_DIR}/../cbqs/src/` (excluding `test.c` and any `.m` files).
   - Adds include directory `${CMAKE_CURRENT_SOURCE_DIR}/../cbqs/src/`.
   - Links against `cmocka-static` and `pthread` and `m`.
   - Registers the test with `add_test(NAME ${NAME} COMMAND ${NAME})`.
5. Adds an option `ASAN` (default OFF). When ON, adds `-fsanitize=address -fno-omit-frame-pointer` to compile and link flags for all test targets.
6. Calls `add_cmocka_test` for: test_intarray, test_expression, test_state.
7. Enables `enable_testing()` so CTest works.

<task type="auto">
  <name>Task 2: Write CMocka tests for intarray, Expression, and state modules</name>
  <files>tests/test_intarray.c, tests/test_expression.c, tests/test_state.c</files>
  <action>
**test_intarray.c** -- Test the bit array operations:
- Include order: `stdarg.h`, `stddef.h`, `setjmp.h`, `cmocka.h`, then `intarray.h`.
- `test_sw_init`: Call `sw_init(64)`, verify `A.bits == 64`, `A.n == 1`, `A.part != NULL`. Call `sw_init(128)`, verify `A.n == 2`. Free with `sw_clear`.
- `test_sw_setbit_tstbit`: Init 128-bit array, set bits 0, 63, 64, 127. Verify each with `sw_tstbit`. Verify unset bits return 0.
- `test_sw_clrbit`: Set bit 10, clear bit 10, verify `sw_tstbit` returns 0.
- `test_sw_flpbit`: Init, verify bit 5 is 0, flip it, verify 1, flip again, verify 0.
- `test_sw_set_ui_0`: Init, set several bits, call `sw_set_ui_0`, verify all bits are 0.
- `test_sw_set_copy`: Init A with some bits set, B = `sw_set(A)`. Verify `sw_cmp(A, B) == 1`. Modify A, verify `sw_cmp(A, B) == 0`. Free both.
- `test_sw_cmp`: Two identical arrays compare equal. Two different arrays compare not-equal.
- Run with `cmocka_run_group_tests`.

**test_expression.c** -- Test expression building and arithmetic:
- Include order: `stdarg.h`, `stddef.h`, `setjmp.h`, `cmocka.h`, then `Expression.h`.
- `test_init_expression`: `init_expression()` returns non-NULL, `expr_size == 0`.
- `test_add_constant`: Create expr, `add_constant(expr, 5)`. Verify `expr_size == 1`, the clause has coefficient 5 and `len_literal == 0` (constant term).
- `test_add_variable`: Create expr, `add_variable(expr, 3)`. Verify `expr_size == 1`, `len_literal == 1`, variable index is 3.
- `test_add_two_variables`: Create expr, `add_variable(expr, 0)`, `add_variable(expr, 1)`. Verify `expr_size == 2`.
- `test_multiply_constant`: Create expr, `add_variable(expr, 0)`, `multiply_constant(expr, 3)`. Verify the coefficient of the clause is 3. NOTE: `multiply_constant` multiplies ALL existing clauses -- so building `3*x0 + 2*x1` requires: create expr1 with `add_variable(0)` + `multiply_constant(3)`, create expr2 with `add_variable(1)` + `multiply_constant(2)`, then `add_expression(expr1, expr2)`.
- `test_add_expression`: Build two single-variable expressions, combine with `add_expression`. Verify combined `expr_size` is sum of both.
- `test_multiply_variable`: Create expr, `add_variable(expr, 0)`, `multiply_variable(expr, 1)`. Verify clause has 2 variables (x0*x1 product term).
- `test_sub_constant`: Create expr with constant 10, `sub_constant(expr, 3)`. Verify constant is 7.
- `test_sense_and_rhs`: Create expr, `add_sense_to_expression(expr, LOWER)`, `add_rhs_to_expression(expr, 42)`. Verify `expr->sense == LOWER`, `expr->rhs == 42`.
- Free all expressions with `free_expression`.
- Run with `cmocka_run_group_tests`.

**test_state.c** -- Test state management:
- Include order: `stdarg.h`, `stddef.h`, `setjmp.h`, `cmocka.h`, then `state.h`.
- `test_init_state`: `int arr[4] = {1, 0, 1, 0}; state_t *s = init_state(0, arr, 4)`. Verify `s != NULL`, `s->tot_profit == 0`, `sw_tstbit(s->vector, 0) == 1`, `sw_tstbit(s->vector, 1) == 0`, etc.
- `test_copy_state`: Init state, `state_t *c = copy_state(s)`. Verify `sw_cmp(s->vector, c->vector) == 1`, `c->tot_profit == s->tot_profit`. Modify original, verify copy unchanged.
- `test_copy_state_inplace`: Init src and dest states (same size). `copy_state_inplace(dest, src)`. Verify vectors match.
- `test_free_state`: Init state, `free_state(s, 1)` -- no crash (ASan will catch leaks).
- `test_init_large_state`: `init_large_state(10, 5)` returns non-NULL array of 5 states.
- Run with `cmocka_run_group_tests`.

Each test file's main function returns the result of `cmocka_run_group_tests(tests, NULL, NULL)` where `tests` is the `CMUnitTest` array.
