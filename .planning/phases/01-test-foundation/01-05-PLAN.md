  <name>Task 1: Create GitHub Actions CI workflow for C and Python tests</name>
  <files>.github/workflows/test.yml</files>
  <action>
Create `.github/workflows/test.yml` with:

```yaml
name: Tests
on:
  push:
    branches: ['*']
  pull_request:
    branches: [main]
```

**Jobs:**

**1. c-tests** (runs on `ubuntu-latest`):
- Checkout code
- Install dependencies: `sudo apt-get update && sudo apt-get install -y cmake build-essential`
- Configure: `mkdir build-tests && cd build-tests && cmake ../tests`
- Build: `cd build-tests && make -j$(nproc)`
- Test: `cd build-tests && ctest --output-on-failure`

**2. c-tests-asan** (runs on `ubuntu-latest`):
- Same as c-tests but with ASan:
- Configure: `mkdir build-tests-asan && cd build-tests-asan && cmake ../tests -DASAN=ON`
- Build: `cd build-tests-asan && make -j$(nproc)`
- Test: `cd build-tests-asan && ctest --output-on-failure`
- Set env: `ASAN_OPTIONS: detect_leaks=1:abort_on_error=1`

**3. python-tests** (runs on `ubuntu-latest`):
- Checkout code
- Setup Python 3.13 (use `actions/setup-python@v5` with `python-version: '3.13'`)
- Install build deps: `pip install cython numpy setuptools`
- Install package: `pip install -e .`
- Install test deps: `pip install pytest`
- Run tests: `pytest tests/ -v --tb=short`

All three jobs run in parallel (no `needs` between them -- they are independent).

**Important notes:**
- The ubuntu-latest runner has gcc and cmake available, but explicitly install them for reliability.
- The Python setup needs Cython to compile the extensions.
- Use `actions/checkout@v4` for checkout step.
- Set `fail-fast: false` if using a matrix (not needed here since jobs are separate).
