  <action>
**test_constraint.c** -- Test constraint data structure and evaluation:
- Include order: `stdarg.h`, `stddef.h`, `setjmp.h`, `cmocka.h`, then `constraint.h`, `Expression.h`, `definitions.h`.
- **Helper function** `build_knapsack_constraint(int n, int64_t *coeffs, int sense, int64_t rhs)`: Creates an expression with `n` weighted variables (each built as separate single-variable expression with multiply_constant, combined via add_expression), sets sense and rhs, adds to a new_constraints_t, returns it. This avoids the multiply_constant-all-clauses pitfall.
- `test_init_new_constraint`: Verify `init_new_constraint()` returns struct with `num_constraints == 0`.
- `test_add_single_expression`: Build expression `2*x0 + 3*x1 <= 5`. Add to constraints. Verify `con.num_constraints == 1`, sense is LOWER, rhs is 5.
- `test_add_multiple_expressions`: Add 3 different constraint expressions. Verify `num_constraints == 3`.
- `test_eval_constraints_satisfied`: Build constraint `x0 + x1 <= 2`. Create state with x0=1, x1=0. After `preprocessing(2, &con)`, call `eval_constraints(&con, sol, 2)`. Expect all satisfied (return value indicates feasibility).
- `test_eval_constraints_violated`: Build constraint `x0 + x1 <= 0`. Create state with x0=1, x1=1. After preprocessing, `eval_constraints` should indicate violation.
- `test_objective_value`: Build objective `-1*x0 - 2*x1` (minimization represented as negative coefficients). Create state x0=1, x1=1. After preprocessing, `objective_value(&obj, sol)` should return -3.
- `test_constraint_violation`: Build constraint `x0 + x1 <= 1`. State x0=1, x1=1. After preprocessing, `constraint_violation(&con, sol, 0)` should return a positive violation value.
- `test_preprocessing`: Build a simple constraint, call `preprocessing(n, &con)`. Verify the sparse/dense index arrays are populated (positive_indices, negative_indices are non-NULL after preprocessing).
- Free all constraints, expressions, and states in each test.

**test_model.c** -- Test model struct management:
- `test_init_model`: `model_t *mod = init_model()`. Verify `mod != NULL`.
- `test_free_model`: Init and free model -- no crash. (ASan catches leaks.)
- `test_model_defaults`: After init, verify key fields have sensible defaults (e.g., `mod->n == 0`, pointers are NULL or initialized).

IMPORTANT: The global `BranchingStats` variable must be reset between tests. Add a setup fixture that calls `memset(&BranchingStats, 0, sizeof(BranchingStats))` or `set_factors(0,0,0,0); set_bias(0);` before each test group.
