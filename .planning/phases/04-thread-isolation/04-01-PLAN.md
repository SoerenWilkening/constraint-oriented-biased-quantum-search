<task type="auto">
  <name>Task 2: Implement prng.c with xoshiro256** and SplitMix64</name>
  <files>cbqs/src/prng.c</files>
  <action>
Create prng.c implementing the xoshiro256** PRNG (reference: https://prng.di.unimi.it/):

1. Includes and thread-local definitions:
   ```c
   #include "prng.h"
   #include <fcntl.h>
   #include <unistd.h>
   #include <time.h>

   __thread prng_state_t g_prng_state;
   __thread int g_prng_initialized = 0;
   ```

2. Helper: `static inline uint64_t rotl(const uint64_t x, int k)` - bit rotation

3. SplitMix64 (for seeding):
   ```c
   static uint64_t splitmix64(uint64_t *state) {
       uint64_t z = (*state += 0x9e3779b97f4a7c15);
       z = (z ^ (z >> 30)) * 0xbf58476d1ce4e5b9;
       z = (z ^ (z >> 27)) * 0x94d049bb133111eb;
       return z ^ (z >> 31);
   }
   ```

4. Implement prng_seed_from_state():
   - Takes prng_state_t* and seed
   - Uses SplitMix64 to expand 64-bit seed to 256-bit state

5. Implement prng_seed():
   - Calls prng_seed_from_state with &g_prng_state
   - Sets g_prng_initialized = 1

6. Implement prng_next() - xoshiro256** algorithm:
   ```c
   const uint64_t result = rotl(g_prng_state.s[1] * 5, 7) * 9;
   const uint64_t t = g_prng_state.s[1] << 17;
   g_prng_state.s[2] ^= g_prng_state.s[0];
   g_prng_state.s[3] ^= g_prng_state.s[1];
   g_prng_state.s[1] ^= g_prng_state.s[2];
   g_prng_state.s[0] ^= g_prng_state.s[3];
   g_prng_state.s[2] ^= t;
   g_prng_state.s[3] = rotl(g_prng_state.s[3], 45);
   return result;
   ```

7. Implement prng_next_double():
   - `return (prng_next() >> 11) * 0x1.0p-53;` (53-bit mantissa precision)

8. Implement prng_next_int(int max):
   - `return (int)(prng_next_double() * max);`

9. Implement prng_jump() with JUMP constants:
   ```c
   static const uint64_t JUMP[] = {
       0x180ec6d33cfd0aba, 0xd5a61266f0c9392c,
       0xa9582618e03fc9aa, 0x39abdc4529b1661c
   };
   ```
   - Loop through 4 jump constants, 64 bits each
   - XOR state accumulator when bit is set
   - Advance state after each bit

10. Implement prng_seed_thread():
    - Copy master state to g_prng_state
    - Call prng_jump() thread_id times
    - Set g_prng_initialized = 1

11. Implement prng_get_entropy_seed():
    - Try /dev/urandom first (open, read 8 bytes, close)
    - Fallback to clock_gettime + getpid() XOR
