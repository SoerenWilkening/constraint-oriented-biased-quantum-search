  <name>Task 1: Replace module-level callback state with per-thread _SolveState in SearchLib.pyx</name>
  <files>cbqs/SearchLib.pyx</files>
  <action>
  Replace the five module-level cdef globals (`python_callback`, `_history_list`, `_history_prev_best`, `_history_original_callback`, `_history_mod`) with a per-thread state dictionary system.

  **1. Add imports at top of file:**
  - Add `import threading` alongside existing imports
  - `time` is already imported as `time_mod`; `logging` will be used in the callback

  **2. Create _SolveState class (plain Python class, NOT cdef):**
  ```python
  class _SolveState:
      """Per-thread/per-solve callback state."""
      __slots__ = ('history', 'prev_best', 'mod', 'original_callback',
                   'start_time', 'mode')
      def __init__(self, mod, original_callback, start_time, mode):
          self.history = []
          self.prev_best = None
          self.mod = mod
          self.original_callback = original_callback
          self.start_time = start_time
          self.mode = mode
  ```

  **3. Replace module-level globals with:**
  ```python
  _solve_states = {}  # dict[int, _SolveState] keyed by threading.get_ident()
  ```
  Keep `cdef object python_callback = None` as-is for backward compatibility -- the `my_callback_c` cdef function still references it. But change `python_callback` to be set to a thread-aware dispatch function (see below).

  **4. Rewrite `_history_callback_fn()` to be thread-safe:**
  - Look up state via `tid = threading.get_ident()` then `state = _solve_states.get(tid)`
  - If state is None, return silently (no state registered)
  - Wrap value computation in try/except; on exception, log warning and skip entry
  - For OPTIMIZE mode: `value = mod.mod[0].global_opt[0].tot_profit * mod.sense`
  - For SATISFY mode: `value = mod.mod[0].con[0].num_constraints + mod.mod[0].global_opt[0].tot_profit` (satisfaction count = num_constraints + tot_profit, since tot_profit is negative)
  - Compute `elapsed = time_mod.monotonic() - state.start_time`
  - Only append if `state.prev_best is None or value != state.prev_best` (improvements only)
  - Append `(value, elapsed)` -- the new 2-tuple format per CONTEXT.md decision
  - After history logic, call `state.original_callback()` if not None (wrapped in try/except with logging.warning)

  **5. Update `run_sampling()` signature to accept `track_history` and `solve_start_time`:**
  - New signature: `cpdef run_sampling(Model mod, object callback, not_stop: list[int], bint track_history, double solve_start_time)`
  - `solve_start_time` is a shared monotonic timestamp set by Model.solve() before Parallel()
  - When `track_history` is True OR `callback` is not None:
    - Set `cb_ptr = <callback_t> my_callback_c`
  - When `track_history` is False AND `callback` is None:
    - Set `cb_ptr = NULL` (zero overhead)
  - When `track_history` is True:
    - `tid = threading.get_ident()`
    - `mode = mod.mod[0].solver`
    - `_solve_states[tid] = _SolveState(mod, callback, solve_start_time, mode)`
    - Set `python_callback = _history_callback_fn`
  - When `track_history` is False but `callback` is not None:
    - Set `python_callback = callback` (direct user callback, no history wrapping)
  - In the `try` block after `with nogil:`:
    - If `track_history`: `history = list(_solve_states[tid].history)`
    - Else: `history = []`
  - In the `finally` block:
    - If `track_history`: `_solve_states.pop(threading.get_ident(), None)`
    - Always: `solver_ctx_free(ctx)`
  - Return tuple stays the same: `(cur_sol, qtg_applications, feasible, arr, t_total, incumb, history, preprocessing_time_ms)`

  **6. Update `run_local_search()` similarly:**
  - New signature: `cpdef run_local_search(Model mod, object callback, bint track_history, double solve_start_time)`
  - Same per-thread state registration pattern as run_sampling
  - Same cleanup in finally block
  - Return tuple: `(cur_sol, history, preprocessing_time_ms, solve_time_ms)`

  **7. Remove the old module-level cdef globals:**
  - Remove: `cdef object _history_list = None`
  - Remove: `cdef object _history_prev_best = None`
  - Remove: `cdef object _history_original_callback = None`
  - Remove: `cdef Model _history_mod = None`
  - Keep: `cdef object python_callback = None` (still needed by `my_callback_c`)

  **IMPORTANT notes:**
  - `my_callback_c()` with its `cdef void my_callback_c() with gil:` signature stays unchanged -- it still calls `python_callback()`. The per-thread dispatch happens inside `_history_callback_fn()`.
  - The `_history_callback_fn` function must be a regular `def` (not `cdef` or `cpdef`) so it can access `_solve_states` dict and be assigned to `python_callback`.
  - Do NOT use `cdef Model mod` inside `_history_callback_fn` -- it must access mod from the _SolveState which is a plain Python object. Access `state.mod` and cast within the function body if needed for C attribute access.
  - The `run_quantum_local_search` function does not use history tracking -- leave its callback handling unchanged.
  - The GIL protects all dict operations since `my_callback_c` uses `with gil:` and registration/cleanup happens with GIL held.

Cleanup happens in `finally` blocks.
