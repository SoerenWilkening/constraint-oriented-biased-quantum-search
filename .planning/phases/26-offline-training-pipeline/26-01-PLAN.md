```python
from sklearn.ensemble import ExtraTreesRegressor
from cbqs.ml.features import FeatureExtractor, VARIABLE_FEATURE_NAMES, INSTANCE_FEATURE_NAMES
import numpy as np
import joblib
import cbqs
```

Constructor `__init__(self, n_estimators=100, random_state=None)`:
- Create ExtraTreesRegressor(n_estimators=n_estimators, random_state=random_state)
- Create FeatureExtractor()
- Set `_feature_names = list(VARIABLE_FEATURE_NAMES) + list(INSTANCE_FEATURE_NAMES)` (20 names)
- Set `_is_fitted = False`, `_n_training_instances = 0`

Private method `_build_feature_matrix(self, model)`:
- Extract var_features via `self._feature_extractor.extract_variable_features(model)` — shape (n_vars, 9)
- Extract inst_features via `self._feature_extractor.extract_instance_features(model)` — shape (11,)
- Tile inst_features: `np.tile(inst_features, (var_features.shape[0], 1))` — shape (n_vars, 11)
- Return `np.hstack([var_features, inst_tiled])` — shape (n_vars, 20)

Method `fit(self, training_pairs)`:
- Validate `len(training_pairs) > 0`, raise ValueError if empty
- For each (model, weights) pair: build feature matrix, collect X and y arrays
- Convert weights to float64 via `np.asarray(weights, dtype=np.float64)`
- `np.vstack` all X matrices, `np.concatenate` all y vectors
- Call `self._regressor.fit(X_combined, y_combined)`
- Set `_is_fitted = True`, `_n_training_instances = len(training_pairs)`
- Return `self` (for method chaining)

Method `predict(self, model)`:
- If not `_is_fitted`, raise RuntimeError("WeightPredictor has not been fitted. Call fit() first.")
- Build feature matrix for the model
- Get raw predictions from `self._regressor.predict(X)`
- Clip to non-negative: `np.clip(raw, 0, None)`
- Return as float64: `.astype(np.float64)`

Method `save(self, path)`:
- If not `_is_fitted`, raise RuntimeError("Cannot save unfitted predictor")
- Build artifact dict with keys: 'model' (the regressor), 'feature_names' (self._feature_names), 'training_date' (datetime.now().isoformat()), 'n_training_instances', 'cbqs_version' (cbqs.__version__)
- `joblib.dump(artifact, path)`

Class method `load(cls, path)`:
- `artifact = joblib.load(path)`
- Build expected feature names: `list(VARIABLE_FEATURE_NAMES) + list(INSTANCE_FEATURE_NAMES)`
- If `artifact['feature_names'] != expected`, raise ValueError with descriptive message including both lists
- Reconstruct predictor via `cls.__new__(cls)`, set `_regressor`, `_feature_extractor`, `_feature_names`, `_is_fitted = True`, `_n_training_instances`
- Return predictor
