  <name>Task 1: Update SearchLib.h/c with ctx parameter and atomic stop</name>
  <files>cbqs/src/SearchLib.h, cbqs/src/SearchLib.c</files>
  <action>
1. Update SearchLib.h:
   - Add #include "solver_ctx.h"
   - Update ctg signature:
     Before: int ctg(model_t *mod, state_t *cur_sol, callback_t callback, incumbents_t *incumbents);
     After: int ctg(solver_ctx_t *ctx, model_t *mod, state_t *cur_sol, callback_t callback, incumbents_t *incumbents);
   - Remove reset_flag() declaration (will be replaced by solver_ctx_request_stop)

2. Update SearchLib.c:
   - Add #include "solver_ctx.h"

   - REMOVE the global stop_flag and handle_signal:
     DELETE: volatile sig_atomic_t stop_flag = 0;
     DELETE: void handle_signal(int signum) { stop_flag = 1; }
     DELETE: void reset_flag() { stop_flag = 0; }

   - Update ctg() function:
     * Add solver_ctx_t *ctx as first parameter
     * KEEP signal handlers but have them set ctx->stop (see note below)
     * Replace: if (stop_flag) return 0;
       With: if (solver_ctx_should_stop(ctx)) return 0;
     * Add periodic stop check in main while loop (every 256 iterations using bitmask):
       Inside the while loop, add:
       if ((rounds & 255) == 0 && solver_ctx_should_stop(ctx)) break;

   - Note on signal handlers: The SIGINT handler needs to set the stop flag on ctx.
     Since signal handlers can't easily access ctx, we have two options:
     a) Keep a global ctx pointer that the signal handler can access
     b) Have Cython check for SIGINT and call solver_ctx_request_stop

     For now, implement option (a) with a static global:
     static solver_ctx_t *g_active_ctx = NULL;

     In ctg():
     g_active_ctx = ctx;
     signal(SIGINT, handle_signal);  // handler sets g_active_ctx->stop
     signal(SIGTERM, handle_signal);
     ... solve ...
     g_active_ctx = NULL;

     Update handle_signal:
     void handle_signal(int signum) {
         if (g_active_ctx != NULL) {
             solver_ctx_request_stop(g_active_ctx);
         }
     }

3. The search_function pointer calls (CSearch_opt, CSearch_opt_sat, CSearch_sat) need ctx.
   These are called via function pointer. Update the function pointer type and calls:

   Change:
   int (*search_function)(state_t *, int, new_constraints_t *, new_constraints_t *, int, int, array_t *, int *);

   To:
   int (*search_function)(solver_ctx_t *, state_t *, int, new_constraints_t *, new_constraints_t *, int, int, array_t *, int *);

   And update the call:
   res = search_function(ctx, cur_sol, j, mod->con, mod->obj, mod->depth_look_ahead, direction, &fulfilled_objective_terms, &samples);
  </action>
