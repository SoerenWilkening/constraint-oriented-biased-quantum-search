<task type="auto">
  <name>Task 2: Implement solver_ctx.c with lifecycle and stop signal</name>
  <files>cbqs/src/solver_ctx.c</files>
  <action>
Create solver_ctx.c implementing all functions declared in solver_ctx.h:

1. solver_ctx_create():
   - malloc sizeof(solver_ctx_t)
   - Initialize branching_stats with same defaults as global BranchingStats:
     * objective_factor = 0
     * obj_dependent = NULL
     * constraint_factor = 0
     * constraint_dependent = NULL
     * bias_factor = 1
     * bias = 5
     * look_factor = 0.0
   - atomic_init(&ctx->stop, false)
   - ctx->timeout_ms = 0
   - ctx->debug_enabled = (getenv("CBQS_DEBUG") != NULL)
   - clock_gettime(CLOCK_MONOTONIC, &ctx->start_time)
   - return ctx

2. solver_ctx_free():
   - Free ctx->branching_stats.obj_dependent if not NULL
   - Free ctx->branching_stats.constraint_dependent if not NULL
   - free(ctx)

3. solver_ctx_request_stop():
   - atomic_store(&ctx->stop, true)

4. solver_ctx_should_stop():
   - Check atomic_load(&ctx->stop), return 1 if true
   - If timeout_ms > 0, check elapsed time:
     * clock_gettime(CLOCK_MONOTONIC, &now)
     * Calculate elapsed_ms
     * If elapsed >= timeout_ms, atomic_store(&ctx->stop, true), return 1
   - Return 0

5. Context-aware setters (mirror existing global setters but operate on ctx->branching_stats):
   - solver_ctx_set_factors: set all four factor fields
   - solver_ctx_set_bias: set bias field
   - solver_ctx_set_obj_dependence: calloc and copy array to ctx->branching_stats.obj_dependent
   - solver_ctx_set_constraint_dependence: calloc and copy array

6. solver_ctx_debug_stats():
   - If !ctx->debug_enabled, return early
   - Calculate elapsed time from start_time
   - fprintf to stderr in JSON format:
     {"type":"solve_stats","elapsed_sec":%.3f,"bias":%.2f,...}

Include solver_ctx.h, stdlib.h, string.h, time.h.
  </action>
  <verify>gcc -c cbqs/src/solver_ctx.c -I cbqs/src compiles without errors</verify>
  <done>All functions implemented, memory management correct (free allocated arrays)</done>
</task>
