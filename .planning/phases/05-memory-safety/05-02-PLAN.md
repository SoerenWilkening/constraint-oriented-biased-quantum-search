<objective>
Replace all VLAs in local_search.c with heap-allocated per-thread buffers and audit ALL allocations to ensure leak-free execution.

Purpose: VLAs like `int64_t totals[C]` with C=10000 allocate 80KB on stack per call. With multiple threads, this risks stack overflow. Per-thread heap buffers allocated once and reused are safe. Additionally, MEM-01 requires that ALL allocations in explore_neighbourhood are freed, not just the new VLA replacements.

Output: VLA-free local_search.c with proper memory management and complete allocation audit.
</objective>

**Part B: Allocate scratch buffers in accept_best_routine()** (around line 304-327)

In the loop that initializes each data[i], add allocation:
```c
for (int i = 0; i < num_threads; ++i) {
    data[i].con = con;
    // ... existing assignments ...
    data[i].ctx = ctx;

    /* Allocate per-thread scratch buffers */
    data[i].thread_totals = malloc(C * sizeof(int64_t));
    data[i].thread_bits = malloc(d * sizeof(int));
    data[i].num_constraints = C;

    if (data[i].thread_totals == NULL || data[i].thread_bits == NULL) {
        /* Handle allocation failure - free already allocated and return */
        for (int j = 0; j <= i; ++j) {
            free(data[j].remainings);
            free(data[j].thread_totals);
            free(data[j].thread_bits);
            sw_clear(data[j].ful_con);
            sw_clear(data[j].ful);
        }
        free(data);
        free(threads);
        free(prog_data.progress);
        free_state(cur_best, 1);
        sw_clear(ful);
        sw_clear(ful_con);
        return -1;  /* Allocation failure */
    }
}
```
