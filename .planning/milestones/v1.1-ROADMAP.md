## Milestone Summary

**Key Decisions:**
- objective_value returns None (not 0) in SATISFY mode
- Per-thread state dict keyed by threading.get_ident() for callback isolation
- track_history defaults to True for backward compatibility
- set_param/get_param validates against _KNOWN_PARAMS set
- _params values take precedence over solve() kwargs over defaults
- pthread_mutex_trylock for non-blocking global_opt protection
- Removed unguarded progress-bar printfs entirely (UI noise, not diagnostic data)
- Field annotation format: Reads/Writes with mutex protection notes

**Issues Resolved:**
- SATISFY mode crashes (4 distinct bugs)
- GCC 15 compilation warnings (type mismatches, implicit declarations, VLAs)
- Callback cross-contamination in concurrent solves
- Branching parameters not propagating from Python API to C solver
- Dead code accumulation (~400 lines removed)

**Issues Deferred:**
- Remove deprecated BranchingStats API entirely (breaking change, deferred to v1.2+)
- Extract local_search_params_t struct (decouple local_search from model_t)
- ThreadSanitizer human verification (GIL protection sound by construction)

**Technical Debt Incurred:**
- Branching.h:110 has TODO comment for future branching rules (INFO, not blocking)
- History callback AttributeError edge case handled by try/except (empty history possible in rare timing)
