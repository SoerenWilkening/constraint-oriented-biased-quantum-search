# Milestone v1.0: CBQS Stabilization & Optimization

**Status:** SHIPPED 2026-02-06
**Phases:** 1-8
**Total Plans:** 35

## Overview

This milestone took the CBQS solver from its initial state -- functional but with critical correctness bugs, thread safety violations, memory leaks, and missing validation -- to a stable, performant engine that researchers can trust for benchmarking and publishing. The work proceeded in strict dependency order: tests first, then correctness fixes, then thread architecture, then memory optimization, then robustness.

## Milestone Summary

**Key Decisions:**
- Cleanup before features: Stabilize foundation before extending branching/integer UX
- Dynamic expression arrays: Fixed-size wastes memory on small expressions, limits large ones
- Encapsulate global state: BranchingStats as global breaks thread safety in parallel solves
- Expression operators return new objects; in-place operators mutate self
- xoshiro256** with SplitMix64 seeding for per-thread PRNG
- Arena allocator (1MB initial, 256KB overflow) for hot-path allocation elimination
- verify=False default on solve() for opt-in verification behavior
- Module-level cdef state for Cython history callback (cpdef cannot use closures)

**Issues Resolved:**
- Use-after-free in accept_best_routine (thread data freed before threads consume)
- Inverted realloc condition in preprocessing (triggered every iteration)
- Expression mutation bug (operators mutated self instead of returning new objects)
- Global BranchingStats data races in parallel solves
- Memory leaks in preprocessing, Cython wrappers, and explore_neighbourhood
- VLA stack overflow risk on large problem instances
- Missing input validation at API boundary

**Issues Deferred:**
- Phase 6 baseline: No Phase 5 performance baseline captured for arena/dyn_expr comparison
- Phase 8 formal verification: Missing VERIFICATION.md (both plans self-checked passed)
- Remaining VLA at local_search.c:286 (not hot-path, acceptable)
- Commented-out VLA code at local_search.c:158,445

**Technical Debt Incurred:**
- Deprecated global BranchingStats and setters in Branching.c (backward compatibility)
- g_active_ctx static global for signal handler access (intentional, limited scope)
- GCC 15 type mismatch warnings (non-fatal)
- SATISFY mode crash in SearchLib.pyx (pre-existing, not in scope)
