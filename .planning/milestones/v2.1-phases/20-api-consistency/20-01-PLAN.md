Unify parameter naming across C/Cython/Python layers and audit _PARAM_DEFS for orphaned or disconnected entries.

Purpose: The look-ahead depth factor is named `look_factor` in C (Branching.h, solver_ctx), but `look_ahead_factor` in Python (_PARAM_DEFS). Per CONTEXT.md, the canonical name must be identical across all layers. Additionally, all _PARAM_DEFS entries must be audited bidirectionally to ensure every entry connects to an actual C field or solver logic, and every C param accessible via set_param/get_param is present in _PARAM_DEFS.

Output: Consistent `look_ahead_factor` name everywhere, clean _PARAM_DEFS with no orphans, audit report, passing test suite.
</objective>
